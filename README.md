# AI Golfer Classification System (Claude API)

## Overview
This project uses a large language model (Claude API) to classify golfers into customer personas based on behavioral and preference data.

It simulates how AI can be applied to customer segmentation in a business context.

## Features
- Python-based API integration
- Structured prompt engineering
- Consistent persona classification
- Output parsing for reuse in downstream applications

## How It Works
1. User input is structured into a prompt
2. The Claude API processes the request
3. The response is parsed into a defined customer persona

## Example
Input: Golfer who plays multiple times per week and purchases premium gear  
Output: Committed Enthusiast

## Key Takeaways
- Prompt structure significantly impacts output consistency  
- Small prompt changes affect both performance and cost  
- AI systems must balance accuracy with efficiency in real-world use  

## Tech Stack
- Python
- Claude API
- Prompt Engineering
